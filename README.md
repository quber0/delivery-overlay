delivery-overlay to overlay na Androida dla dostawców delivery, pozwalający im dodawać dostawy do jednej aplikacji. Aplikacja zawiera:
- Automatyczne obliczanie zarobku na godzinę
- Automatyczne dodawanie obecnej daty dla każdej dostawy
- Automatyczne dodawanie do lokalnej bazy danych, co pozwala na obejrzenie historii poprzednich dni dostarczania.

delivery-overlay is an Android overlay for delivery drivers, which allows them to add their deliveries to one app. The app includes:
- Automatic income per hour calculation
- Automatic current date addition for every delivery
- Automatic local database insertion, which lets you see the history of past days of delivering.
